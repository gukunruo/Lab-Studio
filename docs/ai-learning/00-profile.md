# 学习者画像与目标说明书

> 这份文件是「人设 + 约束」。  
> 换 Claude / ChatGPT / Gemini / Cursor 时，把它和 `HOW-TO-RESUME.md` 一起丢给对方，就能接上进度。

---

## 身份

- 角色：前端开发工程师 → 转 **AI 应用开发工程师**
- 强项：Web 前端、工程化、产品交互、使用 AI 辅助写代码
- 弱项 / 生疏：Python 细节、后端/数据管道、LLM 应用层术语（RAG、Agent 编排等）
- 兴趣：把 AI 接到真实产品里，而不是训练模型

## 工具现状

- IDE / Agent：Cursor、Claude Code
- 模型：Cursor Auto、Gemini、ChatGPT、Claude、GLM 等（按任务切换）
- 有过：少量 API 调用；MCP / Skill 试用
- 只听过名字：LangChain、LangGraph、RAG

## 学习目标（按优先级）

1. **理解**：LLM、Prompt、Context、Tool、RAG、Agent、MCP 各自解决什么问题
2. **会用**：更稳地用 AI 开发与调优（少幻觉、少返工、能复现）
3. **会做**：AI + 前端（或轻全栈）应用：流式对话、检索增强、工具调用、产品化交互
4. **会判**：什么时候用工作流、什么时候用 Agent、什么时候不该上 AI

## 非目标（明确不做）

- 不主攻：深度学习数学、从零训练大模型、CUDA / 分布式训练
- 不追求：背全量框架 API；够用 + 能查文档即可
- 不硬学：与当前工作完全无关的竞赛题算法

## 约束

| 约束 | 说明 |
|---|---|
| 时间 | 工作日每天约 **1 小时** |
| 场景 | 上班时段学习，需可中断、可续学 |
| 产出 | 每天有「自检清单」；每周有可演示的小练习 |
| 语言 | 文档以中文为主；代码标识符英文 |
| 项目 | 学习内容落在 Lab-Studio；文档权威源在 `docs/ai-learning/` |

## 成功标准（4 周后自测）

你应该能：

1. 用自己的话向同事讲清：Token / Context / RAG / Agent / MCP
2. 独立写一个「流式 Chat + 可选工具调用」的最小前后端（或 BFF）
3. 设计一个简单 RAG：文档从哪来、怎么切、怎么检索、怎么回答、怎么评
4. 在 Cursor 里用 Rule / Skill / MCP 固化至少 1 条重复工作流
5. 对一个 AI 功能做成本与延迟的粗略估算，并知道从哪观测

## 教练（AI）应遵守的教法

- 每天 1 小时：少灌输，多对照前端经验打比方
- 先给心智模型与决策树，再给 API 细节
- 练习要能在 30–40 分钟内完成或明确拆到「下次」
- 纠正错误时说明「为什么错」以及「产品里会怎样炸」
- 不默认紫蓝 AI 营销风；技术表达清晰即可
