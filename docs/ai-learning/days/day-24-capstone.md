# Day 24 · 毕业项目：选题与路线图

> Phase 3 · 产品与工程 · ~60 min  
> 标签：`capstone` `portfolio` `roadmap` `graduation`  
> 前置：前 23 天全部  
> 定位：把 23 天学的串成一个可演示作品，沉淀转岗叙事。

## 今日目标

选定一个 1–2 周可完成的 AI + 前端毕业项目；排出 7 天里程碑；明确 MVP 成功长什么样；规划课程后的继续学习。

## 为什么重要

课程结束不是终点。**要有作品沉淀**，转岗叙事才有证据——证明你理解应用层、能做前端集成、能评测与控成本，而不是"会调戏聊天机器人"。23 天学的东西，不落到一个项目里就忘得快。

## 核心概念

### 1. 选题原则

- **窄**：一个主用户任务，别贪多
- **真**：你自己会每周用（dogfooding 是最好的迭代驱动）
- **展**：能演示检索/流式/评测/工具中的**至少两项**
- **控**：1–2 周晚上+周末可做完 MVP（别选要训练模型的）

### 2. 推荐方向（与 Lab-Studio 契合，且前置已具备）

| 方向 | MVP | 用到的课 |
|---|---|---|
| **A. 学习教练** | 基于 `docs/ai-learning` 的 RAG（Retrieval-Augmented Generation，检索增强生成）问答 + 进度追踪 + 流式 | Day 11/12/18/21 |
| **B. 实验台助手** | 问答 apps/worlds 文档与约定，带引用 | Day 11/12/19 |
| **C. 流式 Playground** | 多模型对比 + Prompt 版本 + 简单评测面板 | Day 03/18/21/22 |
| **D. MCP（Model Context Protocol，模型上下文协议）小工具** | 只读检索本仓库文档的 server + 一个 Skill | Day 10/16 |

**首选 A 或 C**：A 把检索+流式+评测全串起来，是 23 天的集大成；C 更偏你前端优势（多模型路由 + 评测面板 UI），转岗叙事最有力。

### 3. 里程碑模板（7 天）

| 天 | 产出 |
|---|---|
| Day 1–2 | API 打通 + 流式 UI 壳（Day 07/08/18） |
| Day 3–5 | 检索或工具（Day 11/12 或 10/16） |
| Day 6 | 引用 / 错误态 / 基本评测集（Day 17/21） |
| Day 7 | 打磨 + README + 成本/限流配置（Day 22） |
| 缓冲 | 留 1–2 天处理意外 |

### 4. MVP 成功标准（呼应 00-profile.md）

- 能跑通主路径（用户问 → 带引用/流式回答）
- 有 ≥10 条评测集，过线分数明确（Day 21）
- 有错误态 + 中止 + 限流配置（Day 17/22）
- README 说明架构与非目标

**别追求全功能**——MVP 砍到能演示主路径 + 两三个增强即可。

### 5. 转岗叙事

用作品说明三件事：

1. **理解应用层**：会调 API、会 RAG、会 tool calling，知道每层发生什么
2. **能做前端集成**：流式 UI、Chat 交互、状态机——你的护城河
3. **能评测与控成本**：有评测集、有成本/延迟观测、有限流

叙事不是"我用了 LangChain"，是"我知道每层发生什么、能做前端集成、能控住生产"。

### 6. 课程后继续

- **加深**：专用向量库（Chroma/Qdrant）、混合检索（BM25（Best Matching 25，经典词频检索算法）+向量）、reranker、追踪平台（LangSmith/LangFuse）
- **加宽**：一条完整业务 Agent（仍 Workflow 优先，Day 15）
- **保持**：每周 1 小时复盘 `docs/ai-learning/` 笔记 + 跑评测集防回归
- **扩宽护城河**：继续把前端工程化（设计系统、可观测、a11y）与 AI 结合——这是你区别于纯 AI 工程师的独特位置

## 动手练习（30–40 min）

1. **四选一或自拟**：写半页「项目说明书」——用户、主路径、非目标、技术栈、用到的课。
2. **排 7 天里程碑**：填上面的模板，标每天产出 + 哪天用哪几课。
3. **MVP 成功标准**：写 3–5 条可勾选的成功标准（含评测集过线分数）。
4. **更新进度**：在 `docs/ai-learning/README.md` 勾选 Day 24，写下毕业项目链接或路径。
