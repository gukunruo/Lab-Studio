# 如何在任意 AI 工具上续学

聊天记录会丢。**以仓库文档为准**，按下面模板即可在新对话里秒续学。

---

## 快速续学（复制整段）

````markdown
请担任我的 AI 应用开发教练（不主攻模型训练）。

## 背景
请先阅读仓库中的这些文件（若你读得到）：
- docs/ai-learning/00-profile.md
- docs/ai-learning/README.md（含进度勾选）
- 今日课程：docs/ai-learning/days/day-XX-….md

## 我的现状
- 最近完成的 Day：
- 今日计划 Day：
- 卡点 / 想复习的概念：
- 可用时间：约 60 分钟

## 请你今天这样教
1. 用 3 句话回顾今日目标与为什么重要
2. 只讲够用的核心概念（对照前端经验）
3. 带我做「动手练习」，卡住就给最小可运行片段
4. 结束前对照「自检清单」提问，并告诉我明天预告
5. 提醒我更新 README.md 里的进度勾选

不要一次灌整周内容。今天只做这一课。
````

把 `day-XX` 换成实际文件名。

---

## 若 AI 读不到仓库

1. 把 `00-profile.md` 全文粘贴
2. 把当日 `days/day-XX-*.md` 全文粘贴
3. 另附一句：`README 进度：已完成 Day …，今天做 Day …`

---

## 三种常用续学场景

### A. 正常上下一课

用上面的「快速续学」模板即可。

### B. 只复习某个概念（例如 RAG）

```text
按 docs/ai-learning/00-profile.md 的画像教我。
我不想开新课，只想用 20 分钟搞懂：RAG。
请：① 一句话定义 ② 一张文字架构图 ③ 三个前端同学常踩的坑 ④ 一个 10 分钟小练习。
```

### C. 用 AI 帮我做产品，同时学习

```text
我在做：【简述功能】
请一边帮我实现，一边标注：这里用到了哪节课的概念（Day XX）。
若我还没学到，先给「够用版」解释，再给实现。
约束：前端栈 Vue；不训练模型；优先可维护的应用层方案。
```

## 换工具时的小提示

| 工具 | 建议 |
|---|---|
| Cursor | `@docs/ai-learning` 引用目录；或把当日 md 拖进对话 |
| Claude Code / CLI | 先 `cat` / 读取当日 md，再开始教 |
| ChatGPT / Gemini 网页 | 粘贴 profile + 当日课；长文可分两次 |
| 团队分享 | 直接发 `docs/ai-learning/` 路径，不依赖某次聊天 |

---

## 教练质量自检（给你用的）

如果对方 AI：

- 上来就堆论文 / 训练细节 → 提醒：应用层，1 小时课
- 只给概念不给练习 → 要求执行「动手练习」
- 一次讲完 5 天 → 要求只做今天 Day

你有权打断并重贴本文件。
